02 Featured

Coding with Koda

Statics problems you can rotate, take apart, and change.

three.js · JavaScript · no build step · Netlify

Statics asks you to reason about forces in three dimensions from a flat drawing on a page. The drawing is the hard part — not the algebra. This site takes the problems from CE 2450 Statics and draws each one as a 3D scene in the browser: you orbit the camera, pull the figure apart layer by layer, drag a slider to change a load, and watch the geometry answer back.

It shows the givens and never the answer. The point is to understand the setup, not to skip it.

Everything is static HTML and JavaScript — no framework, no build step, no server. Each course is a folder with a problems.js file describing its problems declaratively; a shared viewer engine turns those descriptions into scenes, so one improvement to the engine reaches every course at once.

  • A declarative problem format: points, cables, forces, and dimensions, described rather than drawn
  • A shared 3D engine that renders any problem written in that format
  • Sliders that re-solve the geometry live, so a load becomes something you can feel
  • Free-body diagrams that build up step by step alongside the full scene

03 Approach

Three things I keep coming back to

Different surfaces, same instinct: take the thing that is hard to see, and make it plain.

01

Structures you can see

Forces and loads are real but unseeable. Drawing them properly — in three dimensions, where you can move around them — is usually where the understanding actually starts.

02

Tools that carry the dull load

A scheduling system for a haulage company, a viewer for a statics course. Same idea: build the small unglamorous thing well, and the attention it frees goes to the work that needs judgment.

03

Saying it clearly

Three years of helping applicants find the sentence they actually meant. Engineering is not so different — a design nobody can follow is a design that does not get built.
